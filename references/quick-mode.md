# Quick mode

One agent runs the complete workflow in order: create or resume project, ingest, probe, transcribe, make the story cut, render needed HyperFrames sidecars, assemble in Premiere, export, and QC.

Use Quick mode when the user asks for it, the edit is an experiment, or the footage and treatment are simple enough that specialist handoffs would add delay. Keep a short `Plans/edit-plan.md`; no approval artifacts or role receipts are required.

Still preserve sources, version exports, require explicit voice-cloning authorization, and run final QC.

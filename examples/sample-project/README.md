# Sample project

This project contains no committed footage. Generate a local 12-second vertical clip:

```bash
node ../../scripts/sample-fixture.mjs --output Source/generated-sample.mp4
```

Use it to prove source import, a simple silence cut, animated captions, one Sunburst title, audio, Premiere export and FFmpeg QC. Generated `Source/`, `Renders/`, `QC/` and `Final/` media are ignored.
